# MC-307918: sculk world generation

The monolithic development line carries the same SculkSpreader patch as
modular commit `f9e2dcdab465341cebd0468f0deaaf43e415478d`. The world-generation
cursor checks its destination before reading it, within horizontal squared
distance 144 from the origin. A world-generation cursor with no valid move
discharges. Ordinary gameplay spread keeps its existing behavior.

The patch preserves sensor/shrieker checks and WorldGenRegion diagnostics.
It changes generation of new sculk near the former boundary; it does not
repair or rewrite existing terrain, entities or player data. Reverting the
patch restores the previous generator only for future chunks.

The implementation follows the official Mojang 26.3 server's ChargeCursor
and [MC-307918 changelog](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3).
The modular engine passed a fresh localhost reproduction with 49 generated
chunks, zero natural unsafe-read warnings versus 27 in the control, and nine
movement checks. Those results do not establish the monolithic runtime result.
Compilation and runtime evidence for this branch must be recorded separately.
No production deployment or 1.21.11 compatibility is implied.
