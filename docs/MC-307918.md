# MC-307918: sculk world generation

The 26.2 backport bounds world-generation cursor movement before reading a
candidate destination. It follows the official Mojang 26.3 server's
`SculkSpreader.ChargeCursor`: horizontal distance squared at most 144,
and discharge when world generation cannot find a valid destination.
Ordinary gameplay spread is not subject to this world-generation limit.

This preserves the 26.2 sensor/shrieker count in `SculkBlock.canPlaceGrowth`
and the unsafe-read diagnostic in `WorldGenRegion`. It does not skip
out-of-zone sensors or change existing chunks, entities or player data.
New sculk patches near the previous spread boundary can differ, as in the
upstream bug fix. Reverting the patch restores the previous generator for
new chunks; it does not regenerate chunks already written.

Runtime validation is performed only in a fresh localhost fixture, using
the positive reproduction seed and direct checks of the actual engine's
movement methods. Compilation alone does not establish the runtime result.
This change does not establish compatibility with production 1.21.11,
and does not deploy Season Two or restart production.
